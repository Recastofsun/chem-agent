# Chem-Agent 2.0

**Нативное десктопное приложение для предсказания неорганических реакций.** Работает полностью офлайн, без браузера, консоли и облачных API.

## ✨ Что нового в v2.0
- **Нативное окно Windows:** приложение запускается как обычная программа (PyWebView + WebView2).
- **Удобный конструктор:** ввод реагентов, выбор пресетов и условий (температура, давление, объем).
- **Таблица Менделеева:** интерактивная периодическая система с поиском соединений по элементу.
- **3D-визуализация:** просмотр молекул продуктов реакции в реальном времени.
- **Локальная история:** SQLite база данных сохраняет все расчеты между сессиями.
- **Совместимость:** Windows 10/11 (x64). Не требует установки Python.

## 🚀 Установка
1. Скачайте последний релиз `Chem-Agent-Setup-v2.0.0.exe` из раздела [Releases](https://github.com/Recastofsun/chem-agent/releases).
2. Запустите установщик. Он автоматически проверит наличие WebView2 Runtime и предложит установить его при необходимости.
3. После завершения установки запустите приложение через ярлык на рабочем столе или в меню «Пуск».

## 🛠️ Для разработчиков
- **Стек:** Python 3.11, PyWebView, SQLite, Three.js (офлайн).
- **Сборка exe:** `pyinstaller chem-agent.spec`
- **Сборка установщика:** `iscc installer.iss` (Inno Setup)
