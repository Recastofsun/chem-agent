# Известные ограничения: что не реализовано и где система может ошибаться

## Чего нет по сравнению с ТЗ (сознательно)

| Пункт ТЗ | Что сделано | Почему |
|---|---|---|
| ML-потенциалы MACE/NequIP/Allegro | Не используются, статус виден в `/models` и в отчете | Эти модели обучены на кристаллах и требуют 3D-структуры. ΔfG гидратированных ионов, pH и активности они не дают. По формуле без структуры их ответ был бы догадкой |
| DFT (PySCF) | Не используется | Энергия изолированной молекулы в газе ≠ ΔfG твердого вещества или иона в растворе; ошибка пересчета 10-50 кДж/моль больше эффектов, которые нужно предсказать |
| Кинетика ML-TS / NEB | Нет. Есть Эйринг по барьеру пользователя и диффузионный предел для H+ + OH- | Надежной офлайн-модели барьеров для произвольных реакций не существует. Без барьера кинетика = «неизвестно» |
| Модель активности Pitzer | Заменяется моделью Дэвиса с предупреждением | Нет открытого набора параметров взаимодействия под базу CRC |
| База NIST (`nist.db`) и Materials Project (`mp.parquet`) | Вместо них CRC Handbook (`crc.db`) | NIST не отдает таблицы одним файлом; MP - кристаллы из DFT, для растворов не подходит |
| Органика в эталоне | 10 органических реакций помечены как вне области применимости | Продукты органических реакций определяет механизм, а не равновесие: по термодинамике этанол «должен» распасться на CH4 и CO2 |
| Plotly в отчете | Графики - встроенный SVG с подсказками и увеличением | Plotly добавляет 3,5 МБ в каждый отчет; все требования (офлайн, один файл, интерактив) выполнены без него |
| PowerShell 7 обязателен | Скрипты требуют PowerShell 5.1+, написаны на ASCII | Windows PowerShell 5.1 неверно читает кириллицу в файлах без BOM; PowerShell 7 на целевом ПК не найден. `.bat`-обертки берут `pwsh`, если он есть |
| Установка пакета в site-packages | Команда `chem-agent` - обертка в `.venv\Scripts`, пакет запускается из папки проекта | Сборка пакета офлайн требует setuptools в колесах; обертка проще и не ломается от кириллицы в пути |

## Где система может врать

1. **Концентрированные растворы.** Модели Дебая-Хюккеля и Дэвиса верны до ~0,1 и ~0,5 моль/кг.
   Выше активности считаются грубо; для азотной и серной кислоты это компенсируется правилами
   (NO2 против NO, SO2 из горячей H2SO4), а не расчетом. При ионной силе > 5 моль/кг, нехватке
   воды или несошедшемся расчете статус результата - `unreliable`: продукты показываются, но pH и
   активности смысла не имеют.
2. **Кинетические правила - эвристика.** 24 правила в `rules.yaml` описывают известные
   метастабильные системы (сульфат не восстанавливается цинком, N2 инертен, из раствора выпадают
   гидроксиды, а не оксиды, и т. д.). Реакции, про которые правил нет, будут предсказаны по
   термодинамике, даже если в жизни они идут годами. Каждое сработавшее правило показано в отчете;
   правило можно отключить через `options.disabled_rules`.
3. **Температура.** ΔfG(T) пересчитывается при постоянных ΔfH и ΔfS (приближение Улиха). До
   ~500 K погрешность 1-5 кДж/моль, при 1000-1500 K - до 10-20 кДж/моль. Для частиц без ΔfH
   (часть ионов, фазы из Ksp, Cr3+) зависимость от T не учитывается: отчет перечисляет их в
   предупреждении, а погрешность растет на 0,1 кДж/моль на каждый кельвин.
4. **Сухое разложение считается в закрытом объеме при заданном давлении.** Газовая фаза
   появляется, только когда давление продуктов достигает P. В открытом сосуде разложение
   начинается раньше (газ уходит). Для такого случая задайте `atmosphere.mode = "open"`.
   Пример: KHCO3 при 400 K в закрытом объеме по расчету не разлагается.
5. **Нет данных - нет продукта.** В базе 1 248 веществ и ионов CRC и 43 дополнительных значения.
   Если продукта нет в базе (K2MnO4, Ni(NH3)6 2+, P4O10), он не будет предсказан; если нет данных
   о реагенте ((NH4)2CO3, Cu(NO3)2, CaSO3) - ответ «неизвестно».
6. **Аморфные и кристаллические фазы.** Для Fe(OH)3 и Al(OH)3 взяты свежеосажденные аморфные
   фазы (phreeqc.dat). Кристаллические гетит и гиббсит устойчивее, но образуются медленно.
   Гидраты солей в базе CRC есть не для всех солей.
7. **Равновесие, а не выход.** Система отвечает, что будет при бесконечно долгом ожидании с
   учетом правил. Время реакции без заданного барьера не предсказывается.
8. **Эталон частично «видел» разработку.** Правила подбирались, пока шла проверка на эталоне из
   205 реакций, поэтому 90,8 % на нем - оптимистичная оценка. На слепой выборке из 60 реакций - 100 %,
   но она состоит из типовых школьных реакций. На нетиповых задачах точность будет ниже.
9. **Смеси газов без поджигания.** Для H2 + O2, CH4 + O2 и т. п. при T < 700 K показывается
   равновесие (вода, CO2) с предупреждением: без искры или катализатора реакция не начнется.
10. **Аммиачные комплексы.** По данным CRC/NBS Cu(OH)2 и Zn(OH)2 растворяются в 0,1-0,5 М аммиаке
    лишь частично; в лабораторной практике их растворяют в концентрированном аммиаке с солями аммония.
11. **Проверка на Windows не выполнена.** Код и 152 теста прогнаны на Linux (Python 3.11.15),
    скрипты `.ps1` проверены парсером PowerShell 7.4. Windows-специфичные ветки (пути `\\?\`,
    `%LOCALAPPDATA%`, `.bat`) покрыты тестами, но на Linux они идут по другой ветке. Первый запуск
    `install_offline.bat` и `self_test.bat` на Windows - это и есть приемочная проверка пунктов
    12-13 ТЗ.
