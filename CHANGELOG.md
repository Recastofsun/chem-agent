# CHANGELOG

## [Unreleased] — Core v2.3 (Electrochemistry) — ветка `dev`

### Added
- **Двухкамерная электрохимическая ячейка** (`cell` object в API):
  - Анод и катод как независимые камеры с собственными растворами.
  - Мембрана (типы: `cation_exchange`, `anion_exchange`, `porous`, `none`).
  - Внешняя цепь: `galvanostatic` (ток, время) и `potentiostatic` (напряжение).
- **Модуль `chem_agent/electrochem/kinetics.py`:**
  - Уравнение Нернста для расчета равновесного потенциала \(E_{eq}\).
  - Уравнение Батлера-Фольмера (формула Тафеля) для выбора доминирующей реакции.
  - Учет перенапряжения (\(\eta\)) из базы данных.
  - Учет автоионизации воды (`H+` = 1e-7 М при pH 7).
- **Закон Фарадея** в `_run_cell`:
  - Ограничение количества прореагировавшего вещества по току и времени.
  - Прямое изменение концентраций без повторного равновесия Гиббса.
- **Электрохимический сдвиг потенциалов** через `fixed_lambda` (множители Лагранжа для заряда) в `equilibrium.py`.
- **Модель активности SIT** (Specific Ion Interaction Theory) в `thermo/activity.py` для концентрированных растворов (до 6 М).
- **Методы кинетики в `database.py`:** `get_e0`, `get_barrier`, `get_sit` для доступа к новым таблицам БД.
- **Новые таблицы в `crc.db`:**
  - `redox_pairs` (окислитель, восстановитель, \(n\), \(E^\circ\), коэффициенты, перенапряжение, ток обмена).
  - `kinetic_barriers` (энергии активации \(E_a\)).
  - `sit_parameters` (коэффициенты взаимодействия ионов).
  - `electrode_materials` (материалы электродов и токи обмена).
- **Скрипты миграции БД:**
  - `scripts/patch_db_v2_2.py` (электрохимия, кинетика, SIT).
  - `scripts/patch_db_overpotential.py` (перенапряжение).
  - `scripts/patch_db_kinetics_v2.py` (токи обмена).
- **Тесты:** `scripts/test_cell.py`, `scripts/test_cell_v2.py`, `scripts/test_kinetics.py`, `scripts/test_electrolysis.py`.

### Changed
- **`chem_agent/agent.py`:** Полностью переписан метод `_run_cell`. Теперь он не «ломает» математику равновесия, а реализует строгий каскад:
  1. Кинетика (Нернст + Батлер-Фольмер) выбирает доминирующую реакцию.
  2. Закон Фарадея считает количество прореагировавшего вещества.
  3. Концентрации изменяются напрямую (без повторного `solve()` Гиббса).
- **`chem_agent/parser/validator.py`:** Добавлена ветка `mode: "cell"` с валидацией камер, мембраны и внешней цепи.
- **`chem_agent/energy/database.py`:** Метод `__init__` теперь загружает `overpotential_V` и `exchange_current_A_m2` из `redox_pairs`.

### Fixed
- **Критический баг с фиксацией заряда:** Метод `fixed_lambda` в `equilibrium.py` ломал баланс масс. Решение: заряд отключается в кинетическом модуле, а сдвиг потенциала применяется только при выборе реакции (не в солвере равновесия).
- **Критический баг с `IndexError`:** Столбец заряда удалялся из `A`, но `fixed_lambda` пытался обратиться к нему. Решение: отказ от удаления столбца, `fixed_lambda` передается только в тех задачах, где заряд сохранен.
- **Критический баг с `delta_grad == 0.0`:** `trust-constr` не сходился без точного Гессиана. Решение: отказались от `trust-constr`, вернулись к двойственному решателю `equilibrium.py`.
- **Учет перенапряжения O2/Cl2:** До этого кислород окислялся при любом напряжении (даже 1.5 В). Теперь — только при \(U > 1.73\) В.

### Notes
- **UI откладывается** до полного закрытия ядра Core v2.2 и v2.3.
- **Остались задачи:**
  - Замена `forbid_new` в `rules.yaml` на `kinetic_barriers` из БД.
  - Мембранный транспорт (уравнение Нернста-Планка) — на следующей итерации.
  - Учет изменения состава камер со временем (динамика).

## 1.0.0 - 2026-09-29

Первая версия по «ТЗ химия.txt» (версия ТЗ 1.0).

### Что сделано

- Минимизация энергии Гиббса: выпуклая двойственная задача в потенциалах элементов, барьерный метод
  плюс уточнение Ньютоном по активному набору фаз. Водная фаза (растворитель + растворенные
  частицы), идеальная газовая фаза при заданном давлении, чистые твердые и жидкие фазы.
  Баланс масс сходится до 1e-12, решение единственное и детерминированное.
- Локальная база `chem_agent/data/crc.db`: 1 248 веществ и ионов CRC Handbook, 26 значений NBS-1982
  (нейтральные частицы в растворе, аммиакаты), 16 малорастворимых фаз из Ksp, Cr3+ из E0.
  Сборка из сырых таблиц: `python -m chem_agent.data.build`.
- Приоритет источников энергий: запрос > база > (ML, DFT недоступны) > пересчет по T > «неизвестно».
- 24 кинетических правила (`rules.yaml`): редокс-развязка серы(VI), азота, хлора, углерода; N2
  инертен; гидроксиды вместо оксидов в растворе; нет H2 из нейтральной воды; концентрированные
  HNO3/H2SO4; пассивация; запрет радикалов, пероксидов, перхлората, органики из неорганики и др.
  Сработавшие правила показываются в отчете.
- Активности: идеальная модель, расширенный Дебай-Хюккель, Дэвис; A и B считаются из
  диэлектрической проницаемости и плотности воды при T (можно задать вручную); фиксированная
  ионная сила.
- Условия: температура и профиль (ramp/points), давление, объем, масса воды, pH (начальный и
  буферный pH-стат), атмосфера (закрытое газовое пространство или открытая система), катализатор.
- Ранжирование продуктов: осадки и газы, соли в растворе (из ионов), растворенные молекулы, вода.
  Молекулярное и сокращенное ионное уравнения с целыми коэффициентами, ΔG, ΔH, ΔS, K, lg K.
- Неопределенность: ансамбль Монте-Карло по ΔfG всех частиц (8/24/64 члена), линейное
  распространение, вклад частиц в дисперсию ΔG, уверенность = доля членов ансамбля с тем же
  основным продуктом.
- Кинетика: уравнение Эйринга по барьеру пользователя или катализатора, диффузионный предел для
  H+ + OH-, профиль приближения к равновесию.
- Отчеты: JSON, один HTML-файл (встроенные CSS/JS/SVG, светлая и темная темы, сортировка, раскрытие,
  увеличение графиков, печать в PDF), Markdown. UTF-8 без BOM.
- Интерфейсы: CLI (`predict`, `self-test`, `benchmark`, `databases`, `version`), REST API и
  веб-форма на 127.0.0.1, Python SDK.
- Офлайн-защита: при `CHEM_AGENT_OFFLINE=1` блокируются все исходящие соединения, кроме loopback.
- Скрипты Windows: setup/install/build/self_test (.ps1 + .bat), run_cli.bat, run_api.bat.
- Тесты: 152 теста pytest, эталон из 205 реакций и слепая выборка из 60 реакций.
