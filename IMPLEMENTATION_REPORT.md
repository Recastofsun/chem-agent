# Отчет о реализации Chem-Agent 2.0 (Desktop)

Дата: 20.10.2026. ТЗ: `TZ_chem-agent_v2_desktop.md`.

## Итог по критериям приемки (v2.0)

| # | Критерий ТЗ v2.0 | Статус | Как проверено |
|---|---|---|---|
| 1 | Нативное окно (без браузера и консоли) | Выполнен | Приложение запускается как отдельный `.exe` файл с GUI (PyWebView + WebView2). Консоль отключена (`console=False` в PyInstaller). |
| 2 | Отказ от HTTP-сервера | Выполнен | `fastapi`, `uvicorn`, `pydantic` исключены из prod-сборки. Связь JS ↔ Python идет напрямую через `pywebview.api` (Bridge). |
| 3 | Единый контракт ответов | Выполнен | Все методы Bridge возвращают `{status, data, error}`. |
| 4 | Локальная история (SQLite) | Выполнен | История расчетов сохраняется в `%LOCALAPPDATA%\chem-agent\history.db` и доступна между сессиями. |
| 5 | Таблица Менделеева | Выполнен | Интерактивная сетка 118 элементов, клик по элементу выдает список соединений из `crc.db`. |
| 6 | 3D-визуализация | Выполнен | Просмотр молекул через Three.js (офлайн) с возможностью вращения. |
| 7 | Офлайн-поставка | Выполнен | Вся статика (CSS, JS, Three.js) и базы данных упакованы в `.exe`. |
| 8 | Удобство установки | Выполнен | Создан установщик Inno Setup, который сам проверяет наличие WebView2 Runtime. |
| 9 | Пресеты реакций | Выполнен | В Конструктор добавлена загрузка готовых сценариев (нейтрализация, горение и т.д.). |
| 10 | Сквозной расчет | Выполнен | Ввод реагентов в UI передается в ядро `Agent`, результат отображается в виде уравнения и ΔG. |

## Архитектурные изменения по сравнению с v1.0

1. **Интерфейс:** Монолитный HTML, генерируемый на Python (Jinja2), заменен на модульный SPA-подобный фронтенд (Vanilla JS + ES-модули + CSS Grid).
2. **Транспорт:** REST API (localhost) заменен на прямой вызов методов Python из JavaScript через Bridge.
3. **Зависимости:** Из production-сборки удалены `fastapi`, `uvicorn`, `starlette`, `pydantic`, `anyio`. Добавлены `pywebview`, `pythonnet`, `clr-loader`.
4. **Хранилище:** Оперативная память (словарь `_store`), очищавшаяся при перезапуске, заменена на постоянную базу SQLite.

## Версии зависимостей (Production)
- Python 3.11
- Ядро: `numpy`, `scipy`, `Jinja2`, `MarkupSafe`, `PyYAML`
- Desktop: `pywebview==5.4`, `pythonnet==3.0.5`, `clr-loader==0.2.7.post0`
- Тесты: `pytest`

*(Полный список см. в `requirements.txt`)*

## Данные
- CRC Handbook of Chemistry and Physics (1248+ веществ).
- NBS Tables 1982.
- Ksp и E0 из открытых источников.
- 3D-структуры: локальный кэш (`data/3d_cache/`) для базовых молекул (H2O, CH4, CO2, NH3, O2).

## Как проверялось качество (v2.0)
1. Сквозные тесты Bridge (`test_bridge_predict.py`), проверяющие передачу данных из UI в ядро и обратно.
2. Юнит-тесты для SQLite-хранилища (`test_storage.py`).
3. Ручное тестирование установщика (Inno Setup) и собранного `.exe` на чистой конфигурации Windows.
4. Проверка отсутствия сетевых запросов (Three.js и шрифты грузятся локально).
