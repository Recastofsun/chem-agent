--------------------------------------------------------------------------------
0. КОНТЕКСТ
--------------------------------------------------------------------------------

Существует рабочее Python-ядро chem-agent (v1.0):
  - Предсказание продуктов неорганических реакций (минимизация энергии Гиббса)
  - Точность 97.9% на слепой выборке из 100 реакций
  - Работает офлайн, база crc.db (1295 частиц)
  - Есть CLI, REST API, HTML-отчёты
  - Упаковано в один .exe (PyInstaller one-file, 54 МБ)

Задача: переделать интерфейс в полноценное desktop-приложение
с нативным окном, без запуска cmd и без браузера.

--------------------------------------------------------------------------------
1. ЦЕЛЬ
--------------------------------------------------------------------------------

Создать desktop-приложение для Windows, в котором:
  - Пользователь двойным кликом запускает exe.
  - Открывается нативное окно приложения.
  - Пользователь взаимодействует с UI без командной строки и браузера.
  - Приложение работает офлайн.
  - Внутри — все функции chem-agent v1.0 + новое.

Целевая аудитория:
  - Профессиональная версия: химики, студенты, преподаватели.
  - Учебная версия (модуль): школьники, дети.

--------------------------------------------------------------------------------
2. ЦЕЛЕВАЯ ПЛАТФОРМА
--------------------------------------------------------------------------------

  - OS: Windows 10/11 (x64)
  - Python: 3.11.x
  - WebView: WebView2 (встроен в Windows 10 1803+)
  - Без установки Node.js, без браузера, без cmd

--------------------------------------------------------------------------------
3. СТЕК
--------------------------------------------------------------------------------

  Backend:      Python 3.11 + существующий chem_agent/
  Окно:         PyWebView (нативное окно с WebView2 внутри)
  UI:           HTML5 + CSS3 + Vanilla JS (ES-модули)
  3D:           Three.js (локально, в static/vendor/)
  Анимации:     GSAP (локально, в static/vendor/)
  Графики:      существующий SVG-рендер из chem_agent/report/charts.py
  Сборка:       PyInstaller (one-file)
  Хранение:     SQLite (%LOCALAPPDATA%\chem-agent\) для истории
  Настройки:    JSON (%LOCALAPPDATA%\chem-agent\settings.json)

  Отказ от:
    - uvicorn / FastAPI / HTTP-сервера (не нужен в desktop-режиме)
    - npm / node_modules / сборки фронтенда
    - CDN и внешних ресурсов (только локальные файлы)
    - Unity, Godot, Qt — избыточны для этой задачи

      predict: (req) => window.pywebview.api.predict(req),
      history: (filters) => window.pywebview.api.history(filters),
      getReport: (id) => window.pywebview.api.get_report_html(id),
      databases: () => window.pywebview.api.get_databases(),
      settings: () => window.pywebview.api.get_settings(),
      saveSettings: (s) => window.pywebview.api.save_settings(s),
      compounds: (el) => window.pywebview.api.get_element_compounds(el),
      structure3d: (formula) => window.pywebview.api.get_3d_structure(formula),
  };

  // Пример использования
  const result = await api.predict({
      reagents: [{formula: "NaOH", moles: 0.1, phase: "aq"},

      conditions: {temperature_K: 298.15, solvent: {name: "water"}},

9. БАЗА ДАННЫХ СОЕДИНЕНИЙ (для таблицы Менделеева)
--------------------------------------------------------------------------------

Для каждого элемента — список соединений из crc.db.

Новый метод в БД:
  db.find_compounds_by_element("Na") -> [
      {"formula": "NaOH", "name_ru": "гидроксид натрия", "class": "base"},
      {"formula": "NaCl", "name_ru": "хлорид натрия", "class": "salt"},
      ...
  ]

Классификация соединений:
  - base       — основания (OH⁻)
  - acid       — кислоты (H⁺ + неметалл)
  - salt       — соли (металл + кислотный остаток)
  - oxide      — оксиды (O²⁻)
  - hydroxide  — гидроксиды
  - metal      — металлы (простые)
  - nonmetal   — неметаллы
  - gas        — газы
  - complex    — комплексы
