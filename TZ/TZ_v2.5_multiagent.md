АРХИТЕКТУРА PIPELINE (5 ЭТАПОВ)
=====================================================================

3.1. Этапы

Stage 1: Диссоциация реагентов (FeCl3 -> Fe3+ + 3Cl-).
Stage 2: Комплексообразование (Fe3+ + SCN- -> FeSCN2+ -> ...).
Stage 3: Осаждение (если Ksp превышен).
Stage 4: Газовыделение (если P_i > P_sat).
Stage 5: Финальное равновесие (докрутка).

Ранний выход: если на этапе 1 все реагенты израсходованы, идём к этапу 5.
Тупик: если solve() не сходится на этапе 3, пробуем другой порядок этапов, затем fallback на staged balancer, затем status = unknown.

3.2. Где живёт

chem_agent/pipeline/stages.py

chem_agent/pipeline/orchestrator.py

3.3. Что видит пользователь

options.pipeline_mode = compact (по умолчанию): только финальный результат.

options.pipeline_mode = detailed: результат плюс отчёт по этапам в explanation.

STAGED BALANCER
=====================================================================

4.1. Когда используется
Только когда обычный balance() вернул None.

4.2. Алгоритм

Найти промежуточные частицы (комплексы, ионные пары, гидроксо-формы).

Построить граф стадий.

Балансировать каждую стадию.

Суммировать.

Если сумма не сходится, вернуть None.

4.3. Где живёт
chem_agent/search/staged_balancer.py

4.4. Константы beta
Из data/external/ (кэш fetch_external) или из таблицы complex_constants в БД.

PITZER (P0, БЛОКИРУЮЩЕЕ)
=====================================================================

5.1. Формула

ln(gamma_i) = ln(gamma_i_DH) + SUM_j m_j * ( 2beta_ij_0 + (2beta_ij_1 / (alpha^2 * I)) * (1 - exp(-alphasqrt(I))(1 + alpha*sqrt(I))) ) + SUM_j SUM_k m_j * m_k * C_ijk

где alpha = 2.0.

5.2. Таблица pitzer_parameters

CREATE TABLE pitzer_parameters (
ion1 TEXT,
ion2 TEXT,
beta0 REAL,
beta1 REAL,
beta2 REAL,
C_phi REAL,
theta REAL DEFAULT 0.0,
psi REAL DEFAULT 0.0,
source TEXT,
PRIMARY KEY (ion1, ion2)
);

ФОРМАТ УРАВНЕНИЙ
=====================================================================

11.1. Три формы

Молекулярная: CaCO3 + 2HCl -> CaCl2 + CO2 (газ) + H2O
Полная ионная: CaCO3(тв) + 2H+(aq) + 2Cl-(aq) -> Ca2+(aq) + 2Cl-(aq) + CO2(газ) + H2O
Сокращённая ионная: CaCO3(тв) + 2H+(aq) -> Ca2+(aq) + CO2(газ) + H2O

11.2. Сравнение уравнений
Структурное сравнение: словарь {formula: coefficient} плюс фазы. CaCO3(тв) не равно CaCO3(aq).

11.3. Порог отсечения боковых продуктов
Если n_i < max(1e-4, 1e-3 * n_main), продукт игнорируется.
