# ТЗ: Chem-Agent Core v2.3 — Двухкамерная электрохимия

## 1. Цель
Реализовать физически строгую двухкамерную модель электрохимической ячейки (анод + катод + мембрана) с корректным применением метода множителей Лагранжа для минимизации энергии Гиббса с электрохимическими ограничениями. Обеспечить поддержку электролиза, гальванических элементов и транспорта ионов через мембрану.

## 2. Фундаментальные принципы

### 2.1. Почему однокамерная модель не работает
В однокамерной модели все ионы находятся в одном растворе с единым электрическим потенциалом φ. Поскольку раствор электронейтрален (∑zᵢnᵢ = 0), сдвиги химических потенциалов zᵢFφ взаимно уничтожаются, и ΔG реакции не меняется. Электролиз математически неотличим от обычной реакции.

### 2.2. Двухкамерная архитектура
- **Анолит (anode compartment):** окисление, потеря электронов. Потенциал φ_a.
- **Катиолит (cathode compartment):** восстановление, получение электронов. Потенциал φ_c.
- **Мембрана / солевой мост:** обеспечивает перенос ионов для поддержания электронейтральности каждой камеры.
- **Внешняя цепь:** задает напряжение U = φ_c − φ_a и ток I.

### 2.3. Математическая постановка
Для каждой камеры решается **своя** задача минимизации:
  min G(n) при A·n = b − Δn_electrode
где Δn_electrode — изменение количества вещества за счет электродной реакции (определяется по закону Фарадея).

## 3. Математический аппарат

### 3.1. Метод множителей Лагранжа для ККТ
Составляем расширенный лагранжиан:
  L(n, λ, μ) = G(n) + λᵀ(b − A·n) + μᵀ·n
  
Условия ККТ:
  ∂L/∂n = ∇G − Aᵀλ + μ = 0
  A·n = b (баланс масс)
  μᵢ ≥ 0, μᵢ·nᵢ = 0 (дополнительная нежесткость)

Решение: **метод Ньютона-Рафсона** по полной KKT-системе (размерность = n_species + n_components).

### 3.2. Электрохимическое ограничение
На каждом электроде выполняется условие равновесия полуреакции:
  ∑ᵢ νᵢ·μᵢ + n_e·μ_e = 0
где:
- νᵢ — стехиометрические коэффициенты полуреакции
- n_e — число электронов
- μ_e — химический потенциал электронов (уровень Ферми электрода)

Электронный потенциал связан с приложенным напряжением:
  μ_e^cathode − μ_e^anode = −F·U

### 3.3. Уравнение Батлера-Фольмера для кинетики
Плотность тока на электроде:
  j = j₀ · [exp(α_a·n·F·η/RT) − exp(−α_c·n·F·η/RT)]
где:
- η = U − E_eq (перенапряжение)
- j₀ — плотность тока обмена (зависит от материала электрода, концентраций, T)
- α_a, α_c — коэффициенты переноса (обычно 0.5)

### 3.4. Итеративный решатель связи
Внешний цикл (Ньютон по току):
1. Задать начальные φ_a, φ_c с условием φ_c − φ_a = U.
2. Решить равновесие в анодной камере → ток I_a.
3. Решить равновесие в катодной камере → ток I_c.
4. Если |I_a + I_c| > ε, скорректировать φ_a и φ_c (метод Ньютона по производной dI/dφ).
5. Повторять до сходимости |I_a + I_c| < 10⁻⁶ A.

### 3.5. Транспорт через мембрану
Уравнение Нернста-Планка (упрощенное для одномерного случая):
  Jᵢ = −Dᵢ · (dcᵢ/dx + zᵢ·F/RT · cᵢ · dφ/dx)
На каждом шаге итерации корректируем количество ионов в камерах согласно Jᵢ·A_membrane·Δt.

## 4. Архитектура кода

### 4.1. Новые модули
- `chem_agent/electrochem/cell.py` — класс `ElectrochemicalCell` (анод + катод + мембрана)
- `chem_agent/electrochem/chamber.py` — класс `Chamber` (одна камера с электродом)
- `chem_agent/electrochem/electrode.py` — класс `Electrode` (материал, j₀, α)
- `chem_agent/electrochem/membrane.py` — класс `Membrane` (тип, селективность, проводимость)
- `chem_agent/electrochem/coupled_solver.py` — итеративный решатель связи
- `chem_agent/thermo/constrained_lagrange.py` — расширенный KKT-решатель

### 4.2. Изменения в существующих модулях
- `chem_agent/agent.py` — новый метод `predict_cell()`, оставляем `predict()` для однокамерных
- `chem_agent/thermo/equilibrium.py` — добавляем поддержку `electron_chemical_potential` в `EqProblem`
- `chem_agent/parser/validator.py` — новая схема запроса с `cell` объектом
