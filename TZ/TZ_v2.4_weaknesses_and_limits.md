## 1. Снимок текущего состояния (v2.3-dev)

**Термодинамика:**
- Минимизация G через двойственную задачу (потенциалы элементов λ).
- Барьерный метод (Interior Point) + Newton polish по активному набору.
- Водная фаза: идеально-разбавленный раствор с μ_w = g_w − M_w Σm_i.
- Идеальная газовая фаза при заданном P.
- Чистые конденсированные фазы.

**Модели активности:**
- `ideal`, `debye_huckel`, `davies`, `sit` (новое).

**Кинетика:**
- 24 эмпирических правила `forbid_new` в `rules.yaml`.
- Таблица `kinetic_barriers` в БД (пока не используется).
- Эйринг для катализа.

**Электрохимия:**
- Двухкамерная ячейка (`cell`-объект).
- Нернст + Тафель для выбора доминирующей реакции.
- Перенапряжение и ток обмена из БД.
- Закон Фарадея (лимит по току/времени).
- Мембранный транспорт **не реализован**.

**База данных:**
- ~1300 веществ (CRC + supplement).
- `redox_pairs`: ~10 пар.
- `kinetic_barriers`: ~3 записи.
- `sit_parameters`: ~4 записи.
- Нет Pitzer-параметров, нет Генри, нет корреляций σ(dGf).

**Валидация:**
- 100% на синтетической `holdout_100.json`.
- **0 сравнений с реальными экспериментами.**
- **0 сравнений с PHREEQC.**

## 2. Слабости по подсистемам

### 2.1. Термодинамическое ядро (Гиббс)

| ID | Слабость | Влияние | Решение | Цена | Приоритет |
|---|---|---|---|---|---|
| **W-01** | Итерация по γ — простая релаксация (0.5·old + 0.5·new), не Newton | При I > 1 M — медленная сходимость, возможны циклы | Полный Newton по (n, λ, γ) одновременно (GEM, как в PHREEQC) | 2–3 нед | ✅ DONE |
| **W-02** | Ulich-приближение для T-зависимости (dGf = dHf − T·ΔSf, Cp игнорируется) | Погрешность 10–30 кДж/моль при T > 1000 K | Cp-интегрирование (dGf(T) = dHf + ∫Cp dT − T·(S + ∫Cp/T dT)) | 1 нед + данные Cp | ✅ DONE |
| **W-03** | Нет закона Генри для растворения газов | Нельзя моделировать карбонизацию под давлением CO₂, абсорбцию SO₂ | μ_i(aq) = μ_i° + RT·ln(m_i) + RT·ln(H_i·P_i) | 1 нед | 🔥 P0 |
| **W-04** | Нет учёта объёма смешения и осмотического давления | Для мембранных процессов и рассолов ошибки в ΔG | dG_mix + V·ΔP | 1 нед | 🟡 P1 |
| **W-05** | Нет фазовых переходов (T_плав, T_кип) | Вода при 373 K остаётся жидкостью при 1 атм (у нас «закрытый сосуд») | P_sat(T) из Антуана, фазовый флаг | 1 нед | 🟡 P1 |
| **W-06** | Нет полиморфизма (один dGf на формулу+фазу) | Кальцит/арагонит/ватерит — один dGf | Ключ в БД: (formula, phase, polymorph) | 2 нед + данные | 🟢 P2 |

### 2.2. Модели активности

| ID | Слабость | Влияние | Решение | Цена | Приоритет |
|---|---|---|---|---|---|
| **W-07** | SIT — упрощение Pitzer (нет тройных взаимодействий) | При I > 3 M — ошибка γ в 2–3×, а в равновесии — в разы | Pitzer (бинарные + тройные параметры) | 3–4 нед + данные | 🔥 P0 |
| **W-08** | Мало SIT-параметров (4 записи) | В незнакомых системах SIT → Davies | Собрать ε из NEA TDB (~200 пар) | 1 нед + данные | 🟡 P1 |
| **W-09** | Нет Pitzer-параметров | Нельзя обещать точность >20% при I > 2 M (хлор-щелочь) | Собрать β⁽⁰⁾, β⁽¹⁾, β⁽²⁾, C^φ, θ, ψ из литературы | 2–3 нед + данные | 🟡 P1 |
| **W-10** | ε воды — только f(T), без P и I | Ошибки в ΔG при P > 100 bar или I > 5 M | ε(T, P, I) — из литературы (Fernández 1997 и др.) | 1 нед | 🟡 P1 |
| **W-11** | eNRTL не реализован (смешанные растворители) | Вода + этанол + электролит — не моделируем | eNRTL (Chen & Song 2004) | 3–4 нед + данные | 🟢 P2 |

### 2.3. Кинетика

| ID | Слабость | Влияние | Решение | Цена | Приоритет |
|---|---|---|---|---|---|
| **W-12** | `forbid_new` — чёрный список, а не физика | Невозможно расширять без ручной правки YAML | Замена на `kinetic_barriers` (Ea из БД) + правило «Ea > порога → блок» | 1–2 нед | 🔥 P0 |
| **W-13** | Ea без T-зависимости (нет ΔCp‡) | Погрешность в Ea при T > 500 K | Ea(T) = Ea(298) + ΔCp‡·(T − 298) | 1 нед + данные | 🟡 P1 |
| **W-14** | Нет Marcus theory (для внешнесферного OВР) | Нельзя оценить Ea без эксперимента | Marcus: Ea = (λ/4)·(1 + ΔG/λ)², λ из COSMO | 2 нед | 🟡 P1 |
| **W-15** | Нет BEP-корреляции (Brønsted-Evans-Polanyi) | Нет «универсальной» оценки Ea для катализа | Ea = α·ΔG + β (по классам реакций) | 1 нед | 🟡 P1 |
| **W-16** | Катализ — «уменьшение Ea» вручную (нет Langmuir-Hinshelwood) | Нельзя описать покрытие поверхности, отравление | Langmuir-Hinshelwood (адсорбция + реакция) | 2 нед | 🟢 P2 |
| **W-17** | Диффузионный контроль не моделируется | Быстрые реакции (H+ + OH-) могут быть недооценены | Комбинация Эйринга + диффузии (k_obs = 1/(1/k_act + 1/k_diff)) | 1 нед | 🟡 P1 |
| **W-18** | Нет интегрирования по времени для обычных реакций | Нельзя описать эволюцию состава | ODE solver (stiff) + profile | 2 нед | 🟢 P2 |

## 3. Фундаментальные пределы

Это **не баги** и **не TODO**. Это физика/данные/математика, которые нельзя обойти в рамках десктопного офлайн-приложения.

| ID | Предел | Причина | Что можно | Что нельзя |
|---|---|---|---|---|
| **L-01** | Произвольные `dGf` без данных | Не измерено — не предскажем | Precomputed DFT для 500–1000 веществ, cloud-каскад, ML-суррогат | Для экзотических комплексов — всегда «unknown» |
| **L-02** | Произвольные `Ea` без данных | ML-потенциалы дают 5–10 кДж ошибки | Marcus для OВР, BEP для катализа | Точная кинетика для новых реакций — только эксперимент |
| **L-03** | Ультраконцентраты (I > 6–10 M) | Pitzer требует тройных параметров, которых нет | SIT + эмпирическая поправка до 8 M | Точность >5% при I > 10 M — только коммерческие пакеты (OLI, Aspen) |
| **L-04** | Реальная ячейка — это 3D PDE | Lumped-параметр ≠ распределённая система | 1D Nernst-Planck | 2D/3D — только COMSOL/Comsol-like |
| **L-05** | Метастабильность | Без σ (межфазного натяжения) — только эмпирика | CNT для 20–30 ключевых фаз | Для произвольной фазы — эмпирический лаг |
| **L-06** | Органика + неорганика в одном ядре | Разные модели (термодинамика vs кинетика) | UNIFAC/COSMO-RS для LLE | Органические механизмы — только RDKit-проект |
| **L-07** | Живые системы (кровь, клетка) | Слишком много органики, ферментов, липидов | — | «Вне scope», направлять в PhreeqcRM, Visual MINTEQ |
| **L-08** | Точность при σ(dGf) > 3 кДж | 3 кДж ↔ 3× в константе равновесия | Ковариация + Bayesian (снижает неопределённость) | Если σ = 5 кДж — различить два продукта нельзя |
| **L-09** | Полинг-Полинг (идеальный газ при 200 bar) | Нужен EoS | Peng-Robinson для 30 газов | Для смесей с полярными газами — сложнее |
| **L-10** | Нуклеация без σ | Классическая теория требует σ | CNT для 20–30 фаз | Произвольные фазы — эмпирический лаг |
| **L-11** | Идеальный газ без P·ΔV для конденсированных фаз | Нужны V(T) для твёрдых | Учесть V·ΔP при P > 100 bar | Без данных V — только оценка |
| **L-12** | Точность без валидации | 100% на синтетике ≠ 100% на эксперименте | Сравнение с PHREEQC + лабораторные данные | Никогда не узнаем реальную точность без эксперимента |

## 4. Архитектура расширений

Чтобы ничего не «встраивать в ядро», предлагаем слоистую архитектуру:

Orchestrator (agent.py) │
│ - выбор режима (single / cell / geo / bio) │
│ - каскад источников │

Core Engine (equilibrium.py) │
│ - Newton по (n, λ, γ) ← Заменить W-01 │
│ - Pitzer / SIT / eNRTL ← W-07, W-11 │
│ - EoS (PR / SRK) ← L-09 │
│ - Henry ← W-03 │

Extensions (плагины) │
│ ├── electrochem (Nernst-Planck, parallel reactions) │
│ ├── kinetics (Marcus, BEP, Langmuir-Hinshelwood) │
│ ├── lles (UNIFAC, COSMO-RS) │
│ ├── nucleation (CNT) │
│ ├── surfcomplex (CD-MUSIC) │
│ └── ml-surrogate (MACE/DFT) │

Data Sources │
│ ├── crc.db (offline) │
│ ├── supplement.yaml (offline) │
│ ├── precomputed_dft.db (offline) │
│ └── cloud-bridge (online, optional) │

**Принцип:** в ядре — только полный Newton по (n, λ, γ). Всё остальное — плагины с чёткими контрактами.
