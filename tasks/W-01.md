# W-01: fetch_external.py (PubChem)

## Цель
Внешние данные по формуле: PubChem первым, NIST WebBook вторым (ТЗ п. 7). Кэш data/external/{formula}.json.
Нет данных - {"error": "no_data"} в кэше, запись в data/coverage_report.json, status = unknown.

## Решения
- Код в scripts/fetch_external.py, не в chem_agent/: tests/test_offline.py запрещает urllib.request
  в пакете ядра, офлайн-гарантия desktop сохранена. Agent.predict внешние базы не вызывает.
- PubChem: name (п. 7.1) -> проверка M по формуле -> fastformula (Hill) для нейтральных частиц.
  Проверка M нужна: по имени "Xq2" PubChem отдал лекарство XQ2 (M = 573.6).
- Невалидная формула в сеть не уходит: unknown, bad_formula.
- NIST: одна страница - имя и M; список кандидатов (для CaSO4 в нем гидрат, рутил, "Venetian red") -
  до 10 кандидатов, M считается по формуле, помечено computed.
- Лимиты: PubChem 5 запросов/с (ТЗ), NIST 1/с.
- Кэш no_data: not_found не перезапрашивается (до --force), сетевая ошибка - повтор через сутки.
- Офлайн-защита включена (CHEM_AGENT_OFFLINE=1) - сеть не трогаем, кэш не пишем, coverage: offline.
- QCArchive и ChEBI (опционально по ТЗ) не реализованы.

## Файлы
Трогать: scripts/fetch_external.py (новый), tests/test_fetch_external.py (новый),
data/external/ (кэш), data/coverage_report.json.
Не трогать: chem_agent/ (ядро офлайн), ui/, crc.db.
