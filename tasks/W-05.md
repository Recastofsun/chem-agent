# W-05: Photochemical

## Цель
Метод синтеза "фотохимический": параметры wavelength_nm, intensity. Тест: H2 + Cl2 -> 2 HCl под светом (ТЗ п. 9).

## Что сделано
1. chem_agent/synthesis/ (новый пакет, общий для W-05...W-09): conditions.method = {"type": ..., параметры}
   или строка-тип; реестр METHODS, validate_method (вызывается из валидатора), analyze -> result["synthesis"].
   Метод не меняет термодинамику: снимает или задает кинетические ограничения и пишет отчет.
2. synthesis/photochemical.py: модель фотоинициирования.
   - Порог фотолиза реагента = min(hc/D0, граница поглощения): таблица PHOTOLYSIS на 12 частиц
     (Cl2 493 нм, Br2 620, I2 795, F2 400, O2 242, O3 850, H2O2 360, NO2 398, HI 330, AgCl 381, AgBr 463, AgI 443).
   - λ не длиннее порога и intensity_W > 0 -> RuleContext.initiated: снимается gas_mix_no_igniter.
   - Поток фотонов q = P·λ/(h·c·N_A), время превращения n/(q·Φ). Φ: задан пользователем, иначе
     цепная H2 + Cl2 - 1e5 (порядок 10^4-10^6), иначе 1. Оценка при полном поглощении.
   - duration_s короче времени превращения - предупреждение (показан равновесный итог).
   - Фотолиз идет, а реакции нет (AgBr) - предупреждение: эндергоничный процесс, фотостационарное
     состояние равновесная модель не описывает.
3. Параметры: wavelength_nm (обязателен, 100-3000), intensity_W (синоним intensity, по умолчанию 1 Вт),
   quantum_yield, duration_s.

## Отклонения от ТЗ
- "intensity" принята как мощность поглощенного света, Вт (единицы в ТЗ не заданы); имя intensity_W, intensity - синоним.

## Ограничения
- D0 - CRC Handbook; границы поглощения, Φ цепи и ширины запрещенной зоны AgX - оценки, не сверены построчно.
- Фотохимия только снимает кинетический запрет. Продукты, невыгодные термодинамически
  (AgBr -> Ag + Br2, фотосинтез), модель не дает.
- Свет снимает только gas_mix_no_igniter. Остальные кинетические правила (Ea по Эйрингу) свет не трогает.
