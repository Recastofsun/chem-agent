# W-09: Sol-gel

## Цель
Метод "золь-гель": параметры pH, aging_time_h. Тест: Si(OC2H5)4 -> SiO2 (ТЗ п. 9).

## Что сделано
1. scripts/patch_db_teos.py: Si(OC2H5)4(l) - ΔfH -1408,0 ± 2,1 кДж/моль (van der Vis, Cordfunke,
   J. Chem. Thermodyn. 1993), S 533,1 и Cp 364,4 Дж/(моль K) (NIST WebBook), ΔfG = -1035,7 (расчет).
2. synthesis/sol_gel.py:
   - разрешает спирт алкоксигруппы (C2H5OH из OC2H5) - иначе правило "новая органика - только сопряженные формы реагента" его запрещает;
   - t1/2 гидролиза по pH: k = 0,69·[H+] + 0,69·[OH-] + 8e-6 (калибровка: ~100 с при pH 2, ~1 сут при pH 7);
     гелеобразование ~10·t1/2; гель полимерный (pH < 7) или коллоидный (pH > 7);
   - выдержка >= времени гелеобразования: конденсация, твердые оксокислоты центрального элемента
     (Si(OH)4, H2SiO3) исключаются, продукт SiO2; меньше - золь Si(OH)4 с предупреждением.
3. hypotheses.build_system: параметр allowed_products; hydroxides_not_oxides только для металлов.
4. naming.ORGANIC_DISPLAY: C2H5OH, CH3OH, CH3COOH вместо H6C2O, HCH3COO в продуктах и уравнениях.

## Отклонения от ТЗ
- method.pH используется для кинетики и типа геля, в равновесие не подставляется (иначе добавка
  HCl/NaOH для pH появляется среди продуктов).

## Ограничения
- Константы гидролиза - калибровка порядка величины; соотношение вода/TEOS, растворитель, T не учтены.
- SiO2 в расчете - кварц из базы; аморфный гель менее устойчив на ~5 кДж/моль (в предупреждении).

## Критерий приемки
1. TEOS в воде, pH 2, 24 ч: Si(OC2H5)4 + 2 H2O -> SiO2↓ + 4 C2H5OH; pH 7, 1 ч - золь Si(OH)4; без метода - нет реакции.
2. tests/test_synthesis_sol_gel.py: 6 тестов. pytest: 253 passed, 1 skipped.
3. holdout_105 95,2%, reactions.json 92,3% - без изменений.
