# W-14: Pitzer

## Цель
Заменить заглушку Pitzer (фактически Davies) полной моделью Harvie-Moller-Weare (1984).
Критерий ТЗ: phreeqc_01_gypsum = 0.0152 моль/кг (было 0.0219).

## Отклонения от ТЗ
- Формула п. 5.1 ТЗ неполная: нет beta2, нет F-члена с B', alpha = 2.0 для всех пар.
  С ней растворимость гипса 0.0062. Реализована полная модель HMW: alpha1 = 2.0
  (пары с однозарядным ионом), alpha1 = 1.4 и alpha2 = 12 (пары 2:2), f_gamma с b = 1.2.
- В БД не было гипса, только ангидрит CaSO4(s) CRC (log Ksp = -4.19). Даже с полным Pitzer
  это 0.0319. Добавлен CaSO4·2H2O(s): dHf, S, Cp по NBS-1982, dGf подогнан под
  log Ksp = -4.581 (pitzer.dat). NBS dGf = -1797.28 в паре с ионами CRC дает log Ksp = -4.38.
- Валидация сравнивала моли, PHREEQC отдает моляльность. Гипс связывает 2 H2O на моль,
  масса воды падает до 0.962 кг, поэтому scripts/run_phreeqc_validation.py теперь делит на массу воды.
- Модель активности по умолчанию для водных систем: debye_huckel -> pitzer (ТЗ п. 1.2
  «Pitzer вместо SIT/Davies»). Для ячейки (cell) по умолчанию остается sit.
