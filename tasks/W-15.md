# W-15: Пул 100 реакций (ТЗ 13.1-13.2)

## Цель
Пул из 100 реакций по 7 категориям с ожидаемым основным продуктом и структурным уравнением, три прохода
проверки, точность 99% по продукту и уравнению.

## Что сделано
- `scripts/build_pool.py` -> `data/pool_100.json`: нейтрализация 15, осаждение 20, ОВР 20, комплексы 10,
  разложение 12, электрохимия 8, газовые 15. Для каждой реакции - expected_main (+ accept_main) и
  expected_equation (+ accept_equations).
- `chem_agent/benchmark.py`: `parse_equation`, `equations_match` - структурное сравнение: словарь
  {(сторона, состав, фаза ↓/↑): коэффициент / НОД}, порядок слагаемых и запись органики (CH3COONa = NaCH3COO) не важны.
- `scripts/run_pool.py` -> `data/pool_report_100.json`; `scripts/check_pool.py` - три прохода:
  покрытие базы (с проверкой фазы твердых/газовых реагентов), fetch_external для пробелов, ядро против ожиданий
  -> `data/pool_disputed.json` с причинами.
- Электролиз переписан (`chem_agent/electrochem/electrolysis.py`): последовательная модель полуреакций
  (Нернст по ΔGf базы + перенапряжения η_H2 0,4 / η_O2 0,8 / η_X2 0,1 В, напряжение разложения, Фарадей,
  связывание OH-/H+ со зрителями). Прежний режим давал невязку 3e5 и ионную силу 1317.
- Исправления ядра, найденные пулом:
  - `staged_balancer.dissociate` раскладывает и кислоты (HCl -> H+ + Cl-); ионы-продукты диссоциации реагентов
    считаются "присутствующими" (HClO4 + LiOH давал unknown: ClO4- был запрещен как новый перхлорат);
  - `is_organic`: C2-C3 с N/O больше не органика по умолчанию (ацетонитрил вместо NaCN);
  - степень окисления в цианидах: C +2, N -3 (Fe(CN)6-4 выпадал из системы);
  - правило `cyanide_no_hydrolysis` (`scripts/patch_db_cyanide.py`), `ferricyanide_stable` только при
    цианидном комплексе в реагентах, `cyanide_complexes_stable` запрещает свободный цианид;
  - ранжирование: доля продукта min(1, n/ref_min), бонус 1,2 солям с комплексным/гидроксо-ионом;
  - газ в уравнении помечается ↑ и по фазе g.

## Результат
pool_100: 96,0% (продукт 97%, уравнение 96%). Цель 99% не достигнута. Расхождения - `data/pool_disputed.json`:
- r11 (SnCl2 + FeCl3): нет SnCl6-2 в базе;
- c10 (FeCl3 + KSCN): один комплекс FeSCN+2, известная проблема h049;
- d10 (Pb(NO3)2 разложение): нет Pb(NO3)2(тв) в базе, ΔfG и S° в открытых источниках не найдены;
- g03 (2 NO2 = N2O4): по CRC жидкий N2O4 при 298 K стабильнее газа на 0,4 кДж/моль, в пределах погрешности.
Все четыре - пробелы или точность данных, не логика ядра.

holdout_100 95,2% и reactions.json 92,3% - без изменений.
