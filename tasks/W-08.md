# W-08: Mechanochemical

## Цель
Метод "механохимический": параметры rpm, ball_material. Тест: CaCO3 + SiO2 -> CaSiO3 без растворителя (ТЗ п. 9).

## Что сделано
synthesis/mechanochemical.py - модель вспышечной температуры (Schwarz & Koch 1986):
- скорость шара v = π·D·rpm/60 (D = mill_diameter_m, по умолчанию 0,1 м);
- ΔT = 700 K · (v / 5 м/с) · sqrt(ρ_шара / ρ_стали); мокрый помол (water) - ΔT x 0,5;
- материалы: steel, stainless_steel, tungsten_carbide, zirconia, agate, alumina, silicon_nitride;
  предупреждение о примеси от износа шаров;
- зона удара при T + ΔT считается механизмом зон из W-06 (закалка продуктов).

## Ограничения
- Калибровка ΔT - одна точка, порядок величины; конкретную мельницу (масса шаров, заполнение,
  частота ударов) модель не описывает. Время помола только в предупреждении.

## Критерий приемки
1. CaCO3 + SiO2 сухие, 600 об/мин, сталь: CaCO3 + SiO2 -> CaSiO3 + CO2↑ (зона 738 K); 200 об/мин - нет реакции.
2. tests/test_synthesis_mechanochemical.py: 7 тестов. pytest: 247 passed, 1 skipped.
