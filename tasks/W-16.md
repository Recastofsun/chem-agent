# W-16: Пул 1000 реакций (ТЗ 14.4)

## Цель
Финальная приемка: пул 1000 реакций, точность 99% по главному продукту и структурному уравнению.

## Что сделано
- `scripts/build_pool_1000.py` -> `data/pool_1000.json`: 100 ручных реакций W-15 + 900 сгенерированных по
  семействам (кислота x основание, катион x анион по таблице растворимости, ряд активности металлов,
  металл + кислота и вода, ряд галогенов, аммиакаты и гидроксокомплексы, термическое разложение при T и T + 200 K,
  сухой синтез, карбонаты/сульфиды/соли аммония + кислота/щелочь, электролиз при 4 и 6 В). Ожидание - по учебному
  правилу, уравнение подбирается в генераторе (нуль-пространство матрицы элементов и заряда). 900 отобраны
  пропорционально по категориям из 1016; 112 кандидатов исключены из-за пробела данных
  (`data/pool_1000_excluded.json`, записи в `data/coverage_report.json`).
- `scripts/check_pool.py data/pool_1000.json` -> `data/pool_disputed_1000.json` (18 расхождений, у каждого причина).
- Исправления, найденные пулом (первый прогон 92,0%):
  - данные (`scripts/patch_db_pool1000.py`): запись "TiO" была Ti3O5, добавлен настоящий TiO; SnCl2(aq)
    на 140 кДж/моль стабильнее ионов - пересчет по lg β2; ΔfH и S для Mn(OH)2; ΔfG PbF2 из Ksp;
  - правила: Mn(0) был отрезан группой "others" в mn_neutral_stop / mn_alkaline_stop; новое правило
    sulfate_only_inert (сульфат не восстанавливается, если вся сера реагентов - S(VI), Cu2+ это не меняет);
  - `hypotheses`: соль запрещенного иона тоже запрещена (NaHCOO(тв) обходил запрет HCOO-);
  - `agent._no_sublimation`: в открытой сухой системе (P -> 0) не испаряется вещество с давлением пара < 1e-3 бар
    (KCl при 900 K, Ag при 1000 K);
  - `ranker`: NH4+ и OH- из NH3 + H2O не участвуют в распределении анионов по солям (NH4Cl был "главным
    продуктом" при аммиакатах меди);
  - генератор: электролизные газы всегда со стрелкой, аммиакаты в избытке аммиака, гидролиз PO4(3-),
    MnO2 -> Mn2O3 выше 800 K.

## Результат
pool_1000: 98,2% (продукт 99,3%, уравнение 98,2%); по категориям: нейтрализация 100%, осаждение 100%,
электрохимия 100%, ОВР 99%, комплексы 98%, газовые 97%, разложение 88%. Цель 99% не достигнута.
Расхождения: 4 из пула 100 (пробелы данных), 7 - нитраты при T + 200 K в открытой системе (модель P -> 0),
3 - ZnS + кислота в закрытом сосуде, 2 - Sn(II)/Sn(IV), KCl при 1100 K, MnO2/Mn2O3 при 700 K.
pool_100 96,0%; reactions.json 92,3% -> 92,8%; holdout_100 95,2% -> 94,3%: h099 (HgCl2 + SnCl2 1:1) после
исправления SnCl2(aq) дает Hg вместо Hg2Cl2 - при 1:1 олова хватает на восстановление до ртути, фикстура
рассчитана на избыток HgCl2. Фикстура не менялась.
