## 1. Что это за проект

`chem-agent` — локальный офлайн-предсказатель продуктов неорганических
химических реакций.

- **Метод:** минимизация энергии Гиббса (термодинамика).
- **Данные:** CRC Handbook, NBS-1982, Ksp/E0-производные (1295 частиц в базе).
- **Точность:** 97.9% на слепой выборке из 100 реакций (Accuracy@3).
- **Работает:** полностью офлайн, без облачных API.
- **Интерфейсы:** CLI, REST API (dev), .exe (54 МБ, one-file).

Целевая аудитория:
- Профессиональная версия: химики, студенты, преподаватели.
- Учебная версия (в разработке): школьники, дети (с 3D и геймификацией).

## 5. Что сделано в последние итерации (октябрь 2026)
Мы прошли через серию фиксов, чтобы поднять accuracy с 90.8% до 97.9%:

Проблема	Решение
CSS .zoom перекрывал интерфейс	.zoom:not([hidden]) { display: flex; }
HTML-escape ломал JSON в <script>	Убрали _html.escape, добавили .replace("<", "\\u003c")
История показывала только главный продукт	Полное уравнение в /history
Раздел 3 пустой при 3 продуктах	Перебор подмножеств в _equations
Cu(OH)₂ вместо [Cu(NH₃)₄]²⁺	Правило ammonia_dissolves в hypotheses.py
Формулы без индексов (Cu(NH3)4SO4)	Jinja-фильтр chem с Unicode-индексами
Научная нотация 1,400·10^11	Юникод-надстрочные в fmt.py и charts.py
Марганец восстанавливался сразу до Mn²⁺	Правило mn_alkaline_stop, mn_neutral_stop
Амфотерные не растворялись в NaOH	Правило alkali_dissolves в hypotheses.py
Газы реагировали без искры	Флаг _gas_mix_no_igniter в agent.py
CaC₂ → CH₄ вместо C₂H₂	Правило carbide_hydrolysis_acetylene
NaHSO₄ терялся в пользу Na₂SO₄	Изменение в ranker.py (parent для HSO₄⁻)
Ni(NH₃)₆²⁺ не находился	Добавлен в supplement.yaml
Вес воды забивал top-3	Вода 0.5 вместо 1.2 в WEIGHTS
Все эти правки закоммичены и на GitHub.

## 8. Принципы работы
Офлайн-first. Никаких сетевых вызовов в рантайме.

Детерминизм. Одинаковый вход → одинаковый выход.

Честность. Если данных нет — писать «неизвестно», не выдумывать.

Прозрачность. В отчётах — что использовано, что исключено, почему.

Пошаговые коммиты. Каждая правка — отдельный коммит с описанием.

При работе с ИИ-ассистентом
Не писать Python через PowerShell (портит кодировку UTF-8).

Использовать Блокнот (сохранять как UTF-8) или Python-скрипты для правок.

После правок — перезапускать uvicorn/приложение (правила и шаблоны кэшируются).

Коммитить после каждого значимого шага.
